# Privacy Policy

Last Updated: November 6, 2025

## Overview

BugBattle (Miss Information Platform) is committed to protecting user privacy. This policy outlines how we collect, use, and protect your data.

## Data Collection

### Information We Collect

**Account Information:**
- Email address (for authentication)
- Username/display name
- Profile preferences

**Game Activity:**
- Score and progress data
- Challenge completion status
- Leaderboard rankings
- Session timestamps

**Technical Data:**
- IP address (for rate limiting and security)
- Browser type and version
- Device information
- API request logs (temporary, for abuse prevention)

### Information We Do NOT Collect

- Personal identification documents
- Financial information (no payment processing)
- Location data beyond IP-based country detection
- Browsing history outside the platform
- Third-party tracking cookies

## How We Use Your Data

### Primary Uses

1. **Platform Functionality**: Provide game features, authentication, and leaderboards
2. **Security**: Prevent abuse, rate limiting, and fraud detection
3. **Improvements**: Analyze usage patterns to improve the platform
4. **Communication**: Send important updates about your account (opt-in only)

### Data Sharing

We do NOT sell, rent, or share your personal data with third parties, except:

- **Legal Compliance**: When required by law or legal process
- **Security**: To investigate abuse or security incidents
- **Service Providers**: Essential services (hosting, authentication) with strict privacy agreements

## Third-Party Services

### Authentication
- **NextAuth.js**: Handles secure authentication (privacy-focused, no tracking)

### AI Services
- **OpenAI/XAI**: Content analysis (anonymized, no personal data)
- **Tavus AI**: Video generation (category-based, no personal profiles)

### Data Sources
- **RSS Feeds**: Public content aggregation (no user tracking)
- **Wikipedia API**: Fact verification (anonymous requests)

## Data Storage and Security

### Security Measures

- Encrypted data transmission (HTTPS/TLS)
- Secure password hashing (bcrypt)
- Rate limiting and DDoS protection
- Regular security audits
- Secure session management

### Data Retention

- **Active Accounts**: Data retained while account is active
- **Inactive Accounts**: Automatically purged after 2 years of inactivity
- **Deleted Accounts**: All personal data removed within 30 days
- **Logs**: Security logs retained for 90 days maximum

1. **Access**: Request a copy of your data
2. **Correction**: Update incorrect information
3. **Deletion**: Request account and data deletion
4. **Export**: Download your data in machine-readable format
5. **Opt-out**: Disable optional features and communications

## Privacy by Design

### Principles

Our platform is built with privacy in mind:

1. **Data Minimization**: Only collect what's necessary
2. **Purpose Limitation**: Use data only for stated purposes
3. **Storage Limitation**: Delete data when no longer needed
4. **Transparency**: Clear communication about data use
5. **Security**: Strong protections by default

Where possible, data is stored locally:
- Game preferences in browser storage

- Offline capability support
